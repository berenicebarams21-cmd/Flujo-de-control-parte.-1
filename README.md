# Flujo-de-control-parte.-1
Calculadora de ISR en C++ 

Descripción.
Este proyecto consiste en un programa desarrollado en C++ que calcula el Impuesto Sobre la Renta (ISR) de un empleado a partir de su sueldo mensual.

Objetivo.

Desarrollar un programa que utilice estructuras de decisión (if y else) para calcular el ISR de acuerdo con el sueldo ingresado por el usuario.

Funcionamiento.

-El usuario ingresa el sueldo mensual.

-El programa calcula el sueldo anual.

-Determina si el empleado debe pagar ISR.

-Muestra el sueldo anual y el monto del ISR correspondiente.

Lenguaje utilizado.
C++
